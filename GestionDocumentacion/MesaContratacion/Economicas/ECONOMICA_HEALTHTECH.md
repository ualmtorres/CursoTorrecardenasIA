# Oferta económica - HealthTech Solutions

Importe total ofertado: 2.690.000 euros, impuestos excluidos.

## Desglose

| Concepto | Importe |
|---|---:|
| Licencias plataforma 24 meses | 610.000 |
| Portal web y app móvil | 320.000 |
| Implantación funcional | 430.000 |
| Integraciones HIS, MPI, laboratorio, imagen y analítica | 540.000 |
| Seguridad, pruebas de carga y continuidad | 210.000 |
| Migración y conciliación de datos | 260.000 |
| Formación y gestión del cambio | 120.000 |
| Soporte y mantenimiento primer año | 200.000 |
| Bolsa evolutiva incluida | 0 |

## Hipótesis económicas

La oferta incluye 360 horas evolutivas, tres ciclos de migración, pruebas de carga con herramienta especializada y acompañamiento presencial durante seis semanas de arranque.

El coste refleja la asignación de perfiles especializados en interoperabilidad y seguridad. HealthTech indica que no se incluyen evolutivos derivados de cambios normativos no vigentes ni desarrollos sobre sistemas terceros fuera de las interfaces documentadas.

## Costes recurrentes tras el contrato

HealthTech estima un coste anual posterior de 410.000 euros para licencias, soporte 24x7, mantenimiento correctivo, evolutivo menor y actualización de componentes.
