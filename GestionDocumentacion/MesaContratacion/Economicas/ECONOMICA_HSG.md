# Oferta económica - Hospital Systems Group

Importe total ofertado: 1.740.000 euros, impuestos excluidos.

## Desglose

| Concepto | Importe |
|---|---:|
| Licencias plataforma 24 meses | 390.000 |
| Portal web y app móvil | 190.000 |
| Implantación funcional | 280.000 |
| Integraciones | 250.000 |
| Seguridad y pruebas | 75.000 |
| Migración | 85.000 |
| Formación | 55.000 |
| Soporte y mantenimiento primer año | 115.000 |
| Analítica y cuadros de mando | 120.000 |
| Dirección y gestión del proyecto | 180.000 |

## Hipótesis económicas

HSG fundamenta el importe en reutilización de componentes, conectores existentes y metodología acelerada. Incluye 180 horas evolutivas, una migración de ensayo y una migración final. El acompañamiento presencial se limita a los hitos de arranque, piloto y despliegue.

La oferta presupone que HUSA facilitará extracciones normalizadas, entornos disponibles desde el mes 2 y validaciones funcionales en plazos máximos de cinco días laborables.

## Costes recurrentes tras el contrato

HSG estima coste anual posterior de 245.000 euros para licencias y soporte base. Las ampliaciones de integraciones, soporte presencial continuado o migraciones adicionales se cotizarán según tarifa vigente.
