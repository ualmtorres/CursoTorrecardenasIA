# Matriz de riesgos preliminar

| Riesgo | HealthTech | MediNova | HSG |
|---|---|---|---|
| Complejidad técnica | Media | Media | Media |
| Escalabilidad | Baja-media | Media-alta | Media |
| Integraciones | Media | Media-alta | Alta |
| Migración | Baja-media | Media | Alta |
| Dependencia de especialistas | Alta | Media | Media |
| Soporte postimplantación | Media | Media | Alta |
| Calendario | Baja | Media | Alta |
| Coste recurrente | Alta | Media | Baja |

## Notas

HealthTech presenta mayor coste y dependencia de perfiles expertos, pero mayor profundidad técnica. MediNova ofrece equilibrio de precio y producto, con dudas de escalabilidad y experiencia en grandes hospitales. HSG combina experiencia hospitalaria y coste bajo, aunque su planificación, horas de integración, migración y soporte requieren contraste adicional.
