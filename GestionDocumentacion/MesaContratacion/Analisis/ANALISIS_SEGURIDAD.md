# Análisis de seguridad preliminar

## HealthTech Solutions

La oferta cubre MFA, auditoría, cifrado, pruebas SAST/DAST, gestión de vulnerabilidades y evaluación de impacto. Es la propuesta con mayor detalle. Debe aclararse el modelo de acceso de especialistas externos de nivel 3 y la trazabilidad de soporte.

## MediNova Digital

Incluye medidas suficientes para una solución SaaS: cifrado, auditoría, MFA para administradores y controles de acceso. Falta mayor detalle sobre segregación multi-tenant, pruebas de intrusión específicas y respuesta ante incidentes con datos personales.

## Hospital Systems Group

La propuesta menciona controles habituales, pero deja para fase de diseño técnico asuntos relevantes como gestión de secretos y rotación de credenciales. Las pruebas de seguridad tienen presupuesto reducido en comparación con el alcance. Conviene solicitar evidencias y plan detallado antes de adjudicar.

## Observaciones abiertas

* Verificar retención de auditoría de 5 años.
* Confirmar soporte 24x7 ante incidentes de seguridad.
* Asegurar pruebas antes de producción general.
* Revisar localización de datos y accesos de soporte.
